# Customer Segmentation Analysis

## Objective
The goal of this project was to segment customers into behavioral groups in order to support targeted marketing strategies and improve customer retention.

## Dataset
Public customer marketing dataset used for educational and analytical purposes.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Analysis Performed
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Customer clustering using K-Means
- Visualization of customer segments

## Key Findings
The analysis identified 4 distinct customer groups:
- High-value loyal customers
- Price-sensitive customers
- Low-engagement customers
- New potential-growth customers

## Business Recommendations
- Develop retention campaigns for high-value customers
- Create promotions for price-sensitive groups
- Increase engagement strategies for low-activity users
